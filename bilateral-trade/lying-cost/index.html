Bilateral Trade with a Lying Cost

Myerson and Satterthwaite (1983) show that the efficient allocation rule is impossible to implement in the standard setting across all buyer-seller distributions with a positive-length intersection. But what if lying is costly for agents? Formally, I model a lying cost in a direct bargaining mechanism by a disutility of \(\gamma\lvert t-t'\rvert\) where \(t\) is an agent's true value and \(t'\) is his/her reported value. How does this affect the implementability of the efficient allocation rule? It turns out, for a sufficiently high lying cost parameter \(\gamma\), the efficient allocation rule can be implemented for any distributions. This and more are discussed and shown in my paper Bilateral Trade with a Lying Cost.

In the interactive demo, we consider a specific example with the buyer value \(V\sim\operatorname{Uniform}[0,1]\) and the seller value \(C\sim\operatorname{Uniform}[1-\epsilon,2-\epsilon]\) with \(0<\epsilon\leq 1\). Adjust the lying cost parameter and the value supports' overlap to see when the efficient allocation rule is implementable for various mechanism constructions.
